2. Grundsätzliches zur Verarbeitung

Finanz Uhu verarbeitet hochgeladene Umsatzdateien im Browser auf deinem Gerät. Die Anwendung sendet den Inhalt der CSV-Dateien nicht an mich und verwendet nach aktuellem Stand keine Nutzerkonten, Analyse- oder Werbetracker. Umsatzdateien werden standardmäßig nur vorübergehend im Arbeitsspeicher gehalten und nicht dauerhaft im Browser abgelegt.

Schriftarten und Formatierungsbibliotheken werden zusammen mit der Website ausgeliefert; dafür werden keine Verbindungen zu externen Schrift- oder CDN-Anbietern hergestellt. Beim Aufruf der Website werden technisch notwendige Verbindungsdaten an den Hosting-Anbieter übermittelt (siehe Abschnitt 4). Wenn du einen externen Link öffnest, wird eine Verbindung zur jeweiligen Website hergestellt; für deren Datenverarbeitung gilt deren Datenschutzerklärung.

3. Umsatzdateien und lokale Speicherung

Wenn du eine Umsatzdatei auswählst, wird sie im Browser eingelesen und ausgewertet. Standardmäßig bleibt ihr Inhalt nur im Arbeitsspeicher der geöffneten Seite. Beim Neuladen oder Schließen der Seite geht eine nicht gespeicherte Datei verloren. Die Datei wird dabei nicht in Local Storage oder IndexedDB geschrieben.

Mit dem Schloss-Symbol neben „Dateien wählen“ kannst du beim Import ausdrücklich festlegen, dass die ausgewählten Dateien zusätzlich im lokalen Speicher (Local Storage) deines Browsers abgelegt werden. In der Dateiverwaltung kannst du für jede Datei sehen, ob sie dauerhaft gespeichert ist. Dort kannst du die gespeicherte Kopie auch wieder entfernen; die Datei bleibt dann noch bis zum Neuladen oder Schließen der Seite in der aktuellen Sitzung verfügbar. Bereits vor dieser Änderung gespeicherte Umsatzdateien bleiben gespeichert, bis du sie entfernst oder ihre Speicherung ausschaltest.

Kategorien, Suchbegriff und Anzeigeeinstellungen können unabhängig von den Umsatzdateien lokal gespeichert werden. Diese Daten werden nicht an den Website-Betreiber übertragen.

Wenn du in den Einstellungen eine Kategorien-Datei verknüpfst, kann der Browser zusätzlich den dafür erforderlichen Dateiverweis in IndexedDB speichern. Der Zugriff auf die Datei erfolgt nur über die vom Browser bereitgestellte Dateiauswahl und die dort erteilten Berechtigungen.

Du kannst gespeicherte Umsatzdateien einzeln über die Dateiverwaltung der Anwendung aus dem Browserspeicher entfernen. Kategorien kannst du in den Einstellungen zurücksetzen oder ändern. Zusätzlich kannst du die Website-Daten in den Einstellungen deines Browsers löschen. Das Löschen der Website-Daten entfernt auch lokal gespeicherte Dateien, Einstellungen und Dateiverweise. Eine verknüpfte Datei, die du selbst außerhalb des Browsers gespeichert hast, wird dadurch nicht gelöscht.

4. Hosting über GitHub Pages

Diese Website wird als statische Website über GitHub Pages bereitgestellt. Beim Aufruf der Website werden technisch notwendige Verbindungsdaten an GitHub übermittelt, damit die Website ausgeliefert und der sichere Betrieb gewährleistet werden kann. GitHub kann dabei insbesondere IP-Adresse, Anfragezeitpunkt, Browserinformationen und abgerufene Ressourcen verarbeiten. Auf vollständige Server-Protokolle und deren konkrete Speicherdauer habe ich keinen Einfluss. Weitere Informationen findest du in der Datenschutzerklärung von GitHub.

Die verwendeten Bibliotheken einschließlich Bootstrap und Font Awesome werden zusammen mit der Anwendung über denselben Hosting-Anbieter ausgeliefert. Die Icon-Schriftdateien von Font Awesome werden dabei ebenfalls lokal eingebunden. Es werden keine Schriftarten oder Bibliotheken von Google Fonts, jsDelivr oder Cloudflare-CDNs nachgeladen.

Finanz Uhu setzt nach aktuellem Stand keine eigenen Cookies und verwendet keine Reichweitenmessung oder personalisierte Werbung. Die Anwendung nutzt Local Storage für von dir gespeicherte Dateien, Kategorien und Einstellungen sowie gegebenenfalls IndexedDB für die Dateiverknüpfung wie oben beschrieben.
